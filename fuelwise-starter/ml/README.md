# 模型介面（規劃，尚未訓練）

第一版任務：同一台車、多趟行程的事後耗油估計，target = fuel_used_l。

1. 匯出經品質篩選的 trip_features；一趟一列。
2. 依日期切分 train / validation / test；同日、同趟不跨集合。
3. 基準模型：訓練期間總耗油 / 總里程 × 該趟里程。
4. 比較線性模型與樹模型；前處理僅 fit 訓練集。
5. 保存完整 Pipeline、特徵清單、單位、特徵版本、套件版本、時間切分與評估結果。
6. 後端啟動時載入已驗證的模型；每次分析只執行 predict。

不可把本趟 L/100km、燃油費、燃油計數器起訖值放入 X。
沒有載重與坡度資料就保留限制，不以引擎負載代替載重。
第一版以 MAE(L) 與里程基準比較；沒有校準與覆蓋率驗證前不回傳信賴區間。
模型殘差是待調查線索，不是已證明可節省的油量。
部署版與訓練版必須共用同一套特徵計算邏輯。
