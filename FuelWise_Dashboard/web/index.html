資料品質與計算口徑

指標怎麼算？
  • 耗油＝本趟累積燃油末值−首值；距離＝累積里程末值−首值。計數器倒退或端點無效時顯示無法計算。
  • L/100km＝100×耗油÷距離。跨行程比較採相同有效行程的總耗油÷總里程。
  • 時間比例以前一筆狀態持有至下一筆；超過120秒的空檔排除，最後一筆不向後延伸。分母為該指標可判讀的時間。
  • CAN狀態0正常、9異常，依原始欄位對照表。異常CAN不參與引擎與燃油指標；原值仍保留。
  • 速度差分只估計≤30秒區間的平均加速度，不據此判定平台急加減速事件。
  • 原始表電瓶為mV，圖表除以1000換算V。引擎負載有效範圍0–250%，不擅自截成100%。
  • 限速為正且車速有效時才比較；比較結果是觀測超限時間，不是交通違規判定。
  • 燃油階梯不能支持秒級流量或逐秒節油歸因。圖表連線僅為閱讀輔助。
  • 資料沒有道路坡度、貨物重量與氣象；此版不輸出其推估值、因果節油量或AI預測。
