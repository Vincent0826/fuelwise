# 驗證紀錄

以本次提供的完整 data(1).xlsx 實際匯入：

- 493,744 筆來源紀錄、55 個來源欄位。
- 20 台車、3,541 個車輛＋行程分組。
- 無略過紀錄、無摘要計算失敗行程。
- 首趟案例：192 筆、30 km、7 L、3,378 秒。
- 五項核心運算測試通過：時間／停止統計、長間隔、計數器倒退、CAN 異常與事件去重。
- Python 編譯與 JavaScript 語法檢查通過。
- 實際 HTTP API 與 jsdom 頁面邏輯檢查通過：六頁籤、載入行程、圖表設定、游標、區間、原始資料分頁及 CSV 連結。

限制：jsdom 檢查採用模擬圖表渲染器，不能取代真實瀏覽器的視覺與地圖操作驗證。本次尚未完成真實瀏覽器視覺驗證。

此紀錄代表程式讀取與運算檢查，不表示已確認車載感測器的實際準確度。
